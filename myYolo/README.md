# YOLO 图像标注任务管理平台



## 功能列表

### 🔹管理员功能

1. 任务管理：新建、编辑、删除标注任务，批量上传原图
2. 提交审核：查看所有标注提交包，预览原图与 txt 标注内容，审核通过 / 驳回 + 上传驳回截图
3. 日志查看：查看全局所有操作审计日志
4. ECharts 数据大盘：任务状态饼图、标注员完成量柱状图、近 30 天提交折线图
5. 任务列表：分页、按任务标签 / 优先级搜索筛选

### 🔹标注员功能

1. 公共任务列表：浏览所有【待领取】任务，自主认领
2. 我的任务：查看自己认领的任务
3. 原图下载：一键打包下载任务原图 ZIP
4. 提交标注成果：批量上传 txt+classes.txt，等待系统 + 管理员两级审核
5. 查看提交历史、驳回备注与驳回截图

### 🔹全局公共功能

1. 用户登录 / 退出，登录页**JS 图形验证码**（之前学的 Math.random 随机生成）
2. 权限控制：管理员 / 标注员角色区分，视图权限校验 + 模板隐藏无权限按钮
3. AJAX Bootstrap 模态框：新增任务、认领、审核操作，无刷新提交；删除 confirm 弹窗
4. 文件在线预览：原图预览、txt 标注文件内容预览
5. 分页、任务多条件搜索过滤
6. 简易任务超时回收：认领 7 天未提交，任务自动释放变回待领取
